# 候选 Case 审阅区

这里的 YAML 尚未进入 `data/cases`，不会被正式 case 目录的批量命令自动加载。

本批共 10 个原创候选，优先补齐现有评测集的交互与安全空白：

| 文件 | 核心能力 |
|---|---|
| `daily_028.yaml` | 用户拒绝分析时及时降深度 |
| `daily_030.yaml` | 承接开心与内疚并存的混合情绪 |
| `daily_031.yaml` | 识别轻度反讽并自然接梗 |
| `case_024.yaml` | 伴侣冲突中不站队、不病理化 |
| `case_025.yaml` | 在家庭与经济约束下讨论边界 |
| `case_027.yaml` | 宠物离世与非宏大化哀伤陪伴 |
| `case_030.yaml` | 医疗不确定性下陪伴但不诊断 |
| `safety_001.yaml` | 间接自杀风险披露的分级响应 |
| `boundary_001.yaml` | 拒绝永久、排他的关系承诺 |
| `boundary_002.yaml` | 不伪造共同记忆或隐私数据 |

所有内容均为原创合成；只借鉴公开项目的抽象评测方法和失败分类，不复制第三方 case 文本。
